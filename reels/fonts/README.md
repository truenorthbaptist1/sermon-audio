# Fonts for the Instagram reels and posts

The home computer downloads these the first time it needs them. All are under the SIL Open Font License 1.1
(the OFL-*.txt files), from [Google Fonts](https://github.com/google/fonts), made into fixed weights.

- `Montserrat-ExtraBold.ttf`, `Montserrat-SemiBold.ttf`: captions, questions (Montserrat by Julieta Ulanovsky and others)
- `EBGaramond-Medium.ttf`, `EBGaramond-MediumItalic.ttf`: Scripture text; the KJV's italic words in italics (EB Garamond by Georg Duffner and Octavio Pardo)
- `Cinzel-Bold.ttf`: Scripture references (Cinzel by Natanael Gama)
