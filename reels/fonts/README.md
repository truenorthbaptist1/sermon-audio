# Fonts for the Instagram reels

The home computer downloads these the first time it makes a reel (they are used for the subtitles and the quote).

- `Montserrat-ExtraBold.ttf` and `Montserrat-SemiBold.ttf`: Montserrat by Julieta Ulanovsky and others, from
  [Google Fonts](https://github.com/google/fonts/tree/main/ofl/montserrat), made into fixed weights (800 and 600).
  Licensed under the SIL Open Font License 1.1 (`OFL.txt`).
